# Mission: Modern TypeScript Product Delivery

## Why
Move from leading Drupal/PHP projects to confidently designing and delivering modern TypeScript products. Learn through a production-grade multi-user Todo and Canvas application rather than through disconnected examples, and turn its real engineering decisions into reusable lessons.

## Success looks like
- Deliver a product in which Users organize Todo Lists and Canvases within shared Workspaces.
- Design, implement, and explain a modular NestJS/Fastify GraphQL backend and a Next.js frontend.
- Deliver the application securely to GCP Cloud Run with containers, infrastructure as code, GitHub Actions, and production observability.
- Make and communicate sound trade-offs across application architecture, identity, cloud infrastructure, and delivery.
- Operate the repository as an agent-native engineering environment with safe parallel work and stack-specific, reproducible guidance.
- Derive concise Polish-language lessons and reference material from practical work on the application.

## Constraints
- Treat the working application as the spine of the learning experience; lessons follow real product work.
- Keep Fastify and GraphQL in the target stack because they are relevant to the expected professional environment.
- Prefer GCP and Cloud Run; select the OIDC provider after comparison.
- Keep code, domain language, ADRs, and technical documentation in English; explanations and lessons may be in Polish.
- Teach at the level of an experienced technology leader and PHP developer moving ecosystems, not a beginning programmer.
- Do not depend on skills that happen to be installed globally; project-critical agent capabilities must be discoverable and versioned by the repository.

## Out of scope
- Elementary programming instruction.
- A public product or open user registration in the first release.
- Self-hosting an identity provider solely for its own sake.
